## Repository-specific records

### D19 — Lumina Tactile: spatial audio and sensory design without invented solver proof

**Use when:** When developing Lumina's HRTF/BEM direction, spatial-audio studio, material sound, AR previews, or sensory exports.

[Recovered intent] Lumina imagines a material/sensory design environment with mesh analysis, avatar HRTF, spatial placement, audio mixing, personalization, exports, and authored lighting/haptics. The aesthetic is an instrument-like tactile workspace with progressive disclosure and quiet capability activation.

[Observed contradiction] The README calls solver behavior mock-friendly while also making broad real-BEM and cross-platform claims. The inspected route constructs a python command with request-derived frequency/prompt values via exec, writes an uploaded mesh to /tmp, and returns a timestamped SOFA URL without checking that output exists in this function. That is a concrete static-code concern, not proof of exploitation or a full backend audit.

[Repair resolution — proposed] Isolate upload/mesh validation, bounded solver configuration, argument-array process execution, job lifecycle, output verification, and file delivery. Treat solver availability as a capability check. Do not announce a successful render from an invented URL. Keep preview/approximation versus validated HRTF data distinguishable.

[Domain correction] Optical roughness, acoustic absorption, geometry, and HRTF measurement/simulation are separate parameter domains. A shared “material” selector must not silently treat them as interchangeable. Each export target needs an adapter and an actual round-trip test.

[Reimagined horizon] An accessible spatial-audio/material instrument with honest local previews and a qualified research solver lane. It can support sound designers, installations, and learning without requiring all XR targets at launch.

[Carry-forward test] A known mesh/config produces an actual traceable output, verified file format, bounded completion/failure behavior, and audible placement comparison. Mute, headphones guidance, plain controls, and non-haptic alternatives remain first-class.
